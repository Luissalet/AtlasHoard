# Quality bar: Atlas shared disk

The established Hoard theme is the visual authority. This code-led surface
has no approved image comp and makes no comp-fidelity claim.

- Users immediately identify the current project and the exact shared path.
- Shared files lead; native Hoard folders stay one action away.
- File rows, actions, empty states and forms stay readable on desktop and mobile.
- Native originals remain normal files; registration never changes their content.
- Synthetic demonstration content is explicitly labelled.
- Plain local controls, visible focus, restrained motion and no decorative assets.

Viewport evidence uses direct browser captures because its fullPage screenshot
route produced malformed mobile pixels despite correct DOM layout. Direct
captures at 1366x1000, 390x1200 and 1280x900 show the complete populated content
from the document top. This browser clips 1440-pixel captures at 1404 pixels;
1366 keeps the whole desktop header in frame. Review the final JPEG files, not the discarded malformed
captures. The usual browser is 1280x720 and remains vertically scrollable.

Detector ran once over the changed UI. It found no regex patterns, but its
HTML parser dependencies were absent: contrast and computed CSS were not tested.
